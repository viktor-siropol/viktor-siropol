## Featured Project

### BitMarket — Digital Services Marketplace

A deployed full-stack MERN marketplace for digital services with customer, seller and admin flows.

**Live Demo:**  
https://digital-services-marketplace.vercel.app

**Repository:**  
https://github.com/viktor-siropol/digital-services-marketplace

### Main features

- Customer, seller and admin role-based flows
- JWT authentication with HTTP-only cookies
- Product creation, image uploads and admin moderation
- Cloudinary image storage and processing
- Shopping cart, order flow and stock validation
- PayPal Sandbox payment integration
- Seller sales management
- Server-side filtering, sorting and pagination
- Backend and frontend tests
- Deployment on Vercel, Render and MongoDB Atlas

### Tech stack

**Frontend:** React, Vite, Redux Toolkit Query, React Router, Tailwind CSS  
**Backend:** Node.js, Express, MongoDB, Mongoose  
**Auth & Security:** JWT, HTTP-only cookies, CORS, Helmet, rate limiting, role-based access  
**Integrations:** Cloudinary, PayPal Sandbox  
**Testing & Deployment:** Vitest, Supertest, Vercel, Render, MongoDB Atlas
